## 四、修复的 bug（本阶段发现）

| # | bug | 根因 | 修复 |
|---|---|---|---|
| 1 | `requires: []` 的泄露点永不激活 | `!l.requires` 对空数组为 false，`.some()` 空数组返回 false | `!l.requires?.length`（index.js + prompts.js 两处；主线卡 requires 均非空故未暴露） |
| 2 | LLM 给无名角色发明姓名 | prompt 未约束 | 铁律：无名人物用身份称呼 |
| 3 | 全「印证」注册表锁死对峙门 | 生成质量波动 | 校验器：每条暗线 ≥1「矛盾」对（第一步校验可重试自愈）+ chain 门双保险 |
| 4 | stage 型角色对峙 darkLine 落到兜底 DL1 | refactor 只对 chain 型取 darkLine | darkLine 双型必填（卡/校验器/prompt 同步） |
| 5 | S1 不显示故事标题 / document.title 不更新 | 浏览器实测发现 | S1 顶栏+摘要显示《标题》；document.title 随槽位更新 |
