## 6. 用户验收指引

双击 启动开发.cmd → http://localhost:5173 → 开始调查：
1. **钉口供**：问陈默"她去世那晚，你们一起吃的晚饭？"→ 回答旁点「📌 钉住这句」→ 顶栏"证据板（3）"
2. **原文狩猎**：点"案卷原文"→ 翻到开头"一桌菜……松鼠鳜鱼"那段 → 划选任意文字 → 点「以此为证」→ 应命中「朋友圈的松鼠鳜鱼」上板（再划一段环境描写试"无关"反馈）
3. **证据板**：进证据板 → 点「我做的饭」钉卡 → 再点「干净的厨房」（需先在审讯中出示过厨房证据或划选 p30 发证）→ 应出 ⚡矛盾 + 红线
4. 审讯室"发起对峙"按钮在有 DL1 矛盾链后应可点亮（P3 完成演出）
